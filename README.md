# Tracking Active Regions on the Sun

Цель данной работы — с помощью программного пакета SunPy отследить активную область на Солнце по мере её вращения по солнечному диску и сделать вырезы вокруг этой активной области на каждом временном шаге.

В результате получается гифка, отражающая солнечную активность на участке.
